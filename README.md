# AgriGrid Dynamics

> **Autonomous Dual-Use Agrivoltaics & Microgrid Energy Orchestrator**  
> Optimizing crop microclimates and dispatching surplus rural clean energy to the grid.

---

## ⚡ Overview

**AgriGrid Dynamics** is a software orchestration and control layer that bridges precision plant physiology with wholesale electricity markets. By dynamically actuating agrivoltaic solar tracker tilt angles and synchronizing high-draw on-farm equipment (cold storage chillers, groundwater irrigation pumps, grain dryers), the system protects sensitive crop canopies from extreme heat stress and evapotranspiration while monetizing flexible capacity through Virtual Power Plant (VPP) balancing markets.

---

## 🚀 Key Features

- **Interactive 60fps Agrivoltaics Simulator**: Real-time canvas simulation showing motorized PV tilt angles, dynamic shadow casting, crop PAR flux, on-farm cold storage demand response, and high-voltage grid export.
- **Bi-Directional RL Controller**: Multi-objective reinforcement learning optimizing both crop yield value ($/acre) and electricity spot arbitrage ($/MWh).
- **Interactive ROI & Value Calculator**: Dynamic modeler calculating projected annual energy arbitrage, crop yield preservation, and verified carbon offsets.
- **3-Tier Subscription Model**: Transparent software subscription (Pilot, Commercial Scale, Enterprise Grid) paired with performance-based grid revenue sharing.
- **Single-Page Architecture**: High-contrast, responsive modern interface with smooth scroll navigation and dark/light theme toggle.

## 💻 Local Setup & Development

### Prerequisites
- Node.js (v16+) installed

### Quick Start
1. Clone the repository:
   ```bash
   git clone https://github.com/chukwuebukasydney-lgtm/agrigrid_dynamics.git
   cd agrigrid_dynamics
   ```
2. Start the development server:
   ```bash
   node serve.js
   ```
   *or*
   ```bash
   npm start
   ```
3. Open your browser at:
   ```
   http://localhost:3000
   ```

You can also simply open `index.html` directly in any modern web browser.
